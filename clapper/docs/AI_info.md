# Пример ШИМ
[Источник](https://share.google/aimode/wcbaeSugE3K9p92NN)

Сделать ШИМ с независимой и плавной регулировкой частоты и скважности на Arduino можно, но стандартная функция analogWrite() для этого уже не подойдет. Нам придется настраивать внутренние таймеры микроконтроллера ATmega328P напрямую через регистры.
Лучше всего для этой задачи использовать Таймер 1 (Timer 1), так как он 16-битный. Это даст нам очень высокую точность настройки как частоты, так и скважности. Выходной сигнал мы будем снимать с пина 9 (OC1A).

## 🛠 Как это работает (Режим Phase and Frequency Correct PWM)
В этом режиме таймер считает вверх до определенного значения (ICR1), а затем вниз до нуля.

* Частота задается регистром ICR1 (он определяет, как высоко считает таймер).
* Скважность задается регистром OCR1A (он определяет момент переключения сигнала внутри этого диапазона).

## 💻 Скетч для плавной регулировки (с потенциометрами)
Для управления подключите два потенциометра к аналоговым пинам:

* A0 — регулятор частоты.
* A1 — регулятор скважности.
* Выход ШИМ — цифровой пин 9.

``` C
// Настройка пинов
const int freqPot = A0; // Потенциометр частоты
const int dutyPot = A1; // Потенциометр скважности
const int pwmPin = 9;   // Выход ШИМ (Таймер 1, канал А)

void setup() {
  pinMode(pwmPin, OUTPUT);
  
  // 1. Сброс регистров Таймера 1
  TCCR1A = 0;
  TCCR1B = 0;
  TCNT1  = 0;

  // 2. Включаем инвертированный или неинвертированный ШИМ на канале А (пин 9)
  // COM1A1 = 1, COM1A0 = 0 -> Неинвертированный ШИМ
  TCCR1A |= (1 << COM1A1);

  // 3. Включаем режим №8 (Phase and Frequency Correct PWM, вершина счета в ICR1)
  // WGM13 = 1 в TCCR1B
  TCCR1B |= (1 << WGM13);

  // 4. Устанавливаем предделитель (Prescaler) на 8
  // При тактовой частоте 16 МГц таймер будет тикать на частоте 2 МГц (16МГц / 8)
  // CS11 = 1 в TCCR1B
  TCCR1B |= (1 << CS11); 
}
void loop() {
  // Читаем потенциометр частоты (0 - 1023)
  int rawFreq = analogRead(freqPot);
  
  // Переводим в значение для регистра ICR1. 
  // Диапазон ICR1 от 100 до 20000 даст частоту примерно от 50 Гц до 10 000 Гц.
  // Формула частоты: F = F_cpu / (2 * Prescaler * ICR1) -> ICR1 = 1 000 000 / F
  unsigned int icrValue = map(rawFreq, 0, 1023, 20000, 100); 
  
  // Важно: меняем частоту только если показания изменились, чтобы избежать дребезга
  if (ICR1 != icrValue) {
    ICR1 = icrValue;
  }

  // Читаем потенциометр скважности (0 - 1023)
  int rawDuty = analogRead(dutyPot);
  
  // Скважность (OCR1A) не должна превышать вершину счета (ICR1)
  // Расчет от 0 (0%) до icrValue (100%)
  unsigned int ocrValue = map(rawDuty, 0, 1023, 0, icrValue);
  
  OCR1A = ocrValue;

  delay(20); // Небольшая задержка для стабильности АЦП
}
```

## 📊 Какие границы регулировки мы получаем?
При предделителе 8 (как в коде выше):

* Минимальная частота: 50 Гц (ICR1 = 20000)
* Максимальная частота: 10 000 Гц (ICR1 = 100) с сохранением отличной плавности скважности.

Если вам нужен другой диапазон (например, ультразвуковой до 40 кГц или инфранизкий для автоматики), нужно просто изменить делитель частоты (CS11) в блоке setup.

# Про регистры и биты
[Источник](https://share.google/aimode/FtBRJVgU27H0X881C)

Да, это встроенные константы, которые жестко «вшиты» в ядро Arduino IDE (а точнее, в библиотеки компилятора AVR-GCC) для конкретного микроконтроллера — в случае Arduino Uno это ATmega328P.
Их не нужно объявлять в коде, так как они соответствуют реальным физическим структурам внутри процессора. Они делятся на две группы: регистры и номера битов.

------------------------------
## 1. Регистры (TCCR1A, TCCR1B, TCNT1, ICR1, OCR1A)
Это названия специальных 8-битных или 16-битных ячеек памяти (регистров ввода-вывода) внутри процессора. Каждая буква в их названии имеет строгий смысл:

* TCCR1A / TCCR1B (Timer/Counter Control Register 1 A/B) — регистры управления Таймером 1. Записывая туда единицы и нули, мы буквально переключаем электронные «тумблеры» внутри чипа, выбирая режим работы ШИМ и делитель частоты.
* TCNT1 (Timer/Counter 1) — это счетчик. Он физически инкрементируется (увеличивается на 1) с каждым тактом процессора.
* ICR1 (Input Capture Register 1) — регистр захвата. В нашем режиме мы используем его как «потолок» счета для TCNT1, чтобы регулировать частоту.
* OCR1A (Output Compare Register 1 A) — регистр совпадения выхода А. Когда счетчик TCNT1 доходит до значения в этом регистре, пин 9 физически переключается (изменяется скважность).

С технической точки зрения компилятор воспринимает их как указатели на определенные адреса в оперативной памяти (например, TCCR1A привязан к адресу 0x80).

------------------------------
## 2. Имена битов (COM1A1, WGM13, CS11)
Регистры состоят из 8 бит (ячеек для 0 или 1). Чтобы программисту не нужно было помнить, какой бит за что отвечает, каждому из них дали текстовое имя. Это константы, которые просто равны порядковому номеру бита (от 0 до 7) в конкретном регистре.

* COM1A1 (Compare Output Mode for Channel 1A, bit 1) — равен 7. Отвечает за поведение пина 9 при совпадении счетчика.
* WGM13 (Waveform Generation Mode for Timer 1, bit 3) — равен 4. Отвечает за выбор режима генерации ШИМ.
* CS11 (Clock Select for Timer 1, bit 1) — равен 1. Отвечает за настройку предделителя (скорости тиканья таймера).

------------------------------
## Зачем нужна конструкция (1 << WGM13)?
Оператор << — это побитовый сдвиг влево. Полноценная запись TCCR1B |= (1 << WGM13); переводится для процессора так:

«Возьми единицу, сдвинь её влево на 4 позиции (так как WGM13 равен 4) и запиши получившийся бит в регистр TCCR1B, не затронув остальные биты».

В двоичном виде это превращается в 0b00010000. Такой подход делает код читаемым. Без этих констант настройка таймера выглядела бы как абсолютно непонятный набор цифр:

TCCR1A = 0x80; // Что это? Зачем?
TCCR1B = 0x12; // Невозможно догадаться без даташита

Хотите, мы разберем, как именно изменение конкретного бита влияет на сигнал, или перейдем к настройке диапазона частот под ваши потенциометры?

## Тот же скрипт, но с ограничением скважности 50%

[Диалог с ИИ](https://share.google/aimode/QVcjCdlPbeAlLJmjo)

```C++
const int freqPot = A0; // Потенциометр частоты
const int dutyPot = A1; // Потенциометр скважности
const int pwmPin = 9;   // Выход на MOSFET

void setup() {
  pinMode(pwmPin, OUTPUT);
  
  TCCR1A = 0;
  TCCR1B = 0;
  TCNT1  = 0;

  // Неинвертированный ШИМ на пине 9
  TCCR1A |= (1 << COM1A1);

  // Режим №8 (Phase and Frequency Correct PWM, вершина в ICR1)
  TCCR1B |= (1 << WGM13);

  // Предделитель на 8 (частоты ~50 Гц - 10 кГц)
  TCCR1B |= (1 << CS11); 
}

void loop() {
  // 1. РЕГУЛИРОВКА ЧАСТОТЫ
  int rawFreq = analogRead(freqPot);
  // ICR1 определяет период. 20000 = ~50 Гц, 100 = ~10 000 Гц
  unsigned int icrValue = map(rawFreq, 0, 1023, 20000, 100);
  
  if (ICR1 != icrValue) {
    ICR1 = icrValue;
  }

  // 2. РЕГУЛИРОВКА СКВАЖНОСТИ (БЕЗОПАСНАЯ)
  int rawDuty = analogRead(dutyPot);
  
  // Жесткое ограничение: скважность максимум 50% от периода (icrValue / 2)
  // Если вам нужно поднять предел, например, до 70%, замените на: (icrValue * 0.7)
  unsigned int maxSafeDuty = icrValue / 2;
  
  // Масштабируем поворот потенциометра от 0% до безопасного максимума
  unsigned int ocrValue = map(rawDuty, 0, 1023, 0, maxSafeDuty);
  
  OCR1A = ocrValue;

  delay(20); 
}
```
